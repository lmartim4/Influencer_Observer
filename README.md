# CSC_51054_EP - Apprentissage profond

[Influencer or Observer: Predicting Social Roles](https://www.kaggle.com/competitions/influencers-or-observers-predicting-social-roles)

**Important**: The notebook requires `features.pkl` to load and requirements.txt packages to be installed.

If you want to generate `features.pkl` yourself:
1. Place `train.jsonl` and `kaggle_test.jsonl` in the same folder as the notebook
2. Run the preprocessing section in the Jupyter notebook

Otherwise, simply run [FinalNotebook_v1.ipynb](FinalNotebook_v1.ipynb) with the provided `features.pkl` (Skipping pre processing)
